# Changelog

NiceTerm keeps the upstream version numbering (forked from NyaTerm 1.2.6).

## 1.2.6

- Initial fork release of NiceTerm, based on [NyaTerm](https://github.com/nyakang/nyaterm) v1.2.6.
- Rebranded the workspace, bundles, crates, data directory (`~/.niceterm`) and deep links to NiceTerm.
- Upstream features: SSH / local / Telnet / Serial / RDP / VNC sessions, SFTP file management, tunnels, OTP, AI assistant, encrypted cloud sync and backups.
